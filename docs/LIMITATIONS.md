## わかっている制限

- **本物のAIでの通し確認は、まだ回数が少ないです。** 公開中のWeb版（v0.35.0）で、本物のAIを使った3人の会議を、預ける → 会議 → 確認 → 承認 → 決定まで通しました（会議は3分35秒）。自動テストは見本の応答で行っています。
- **代表者の画面が必要（追加の関数を入れない場合）**：会議と締切での自動開始は、代表者のアプリ（ページ）が開いているときに進みます。下の「会議をサーバーで進める」を入れると、だれの画面も開いていなくても進みます。ただし、**この関数は本物のSupabase上ではまだ通し確認をしていません**（中身は手元のテストで確認済み）。
- **ページを閉じているときの通知はありません。** スマホへのプッシュ通知には、通知用のサーバーと端末の登録が要るため、まだ作っていません。
- **端末の引き継ぎはWeb版で受ける**：引き継ぎリンクを開けるのはブラウザ（Web版）です。すでに別の人として参加しているブラウザでは引き継げません。
- **文字で答える手間**：質問には選択肢のボタンで答えられます。長く書くときは、スマホではキーボードのマイクで話して入力すると楽です。デスクトップ版には「声で入力」のボタンがあります（Windowsの音声入力を呼び出します）。
- **デスクトップ版は署名なし**：インストール時に警告が出ます。Windows専用です。
- **1つの会議で1議題**：別の議題は、新しい会議を作って扱います。
- **参加の制限がない**：招待コードを持っていれば誰でも参加でき、AIも使えます。
